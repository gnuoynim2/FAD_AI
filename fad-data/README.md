# 한국 반짝 유행(Fad) 예측 — 데이터 수집

| 폴더 | 하는 일 | 언제 |
|---|---|---|
| `buzz/` | 블로그·카페·뉴스 언급량과 구매 신호를 **매일** 쌓음 (과거 기록을 다시 받을 수 없는 지표) | 오늘부터 EC2에서 매일 자동 실행 |
| `trend/` | 네이버 데이터랩 **2016년부터 과거 검색량**을 받고, 반짝 유행/트렌드/계절을 자동 판정 | 키워드 목록이 늘 때마다 실행 |

두 폴더 모두 NAVER API HUB 키를 각 폴더의 `.env`에 넣어서 쓴다. `.env`와 `output/`은 GitHub에 올리지 않는다.
자세한 사용법은 각 폴더의 README를 본다.
