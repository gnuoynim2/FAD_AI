# 유행 키워드별 가게 개업·폐업 분석

행정안전부 음식점 인허가 파일에서 **가게 이름에 유행 키워드가 들어간 곳**을 찾아, 언제 열고 언제 닫았는지 센다.

## 준비
1. 공공데이터포털에서 받은 CSV(휴게음식점, 일반음식점, 제과점 등)를 `stores/data/`에 넣는다. 파일이 커서 GitHub에는 올리지 않는다(`.gitignore` 처리됨).
2. `pip install -r requirements.txt`
3. 검색량과 비교하려면 `trend/`에서 `collect_trend.py` → `label_fads.py`를 먼저 실행해 둔다. (없어도 개업·폐업 집계는 됨)

## 키워드
`trend/keywords.txt`를 그대로 쓴다. 가게 이름 검색어를 따로 정하려면 **5번째 칸**에 쓰고, 앞에 `-`를 붙이면 제외어가 된다. 띄어쓰기는 무시한다("탕 후루"도 "탕후루"로 찾음).
```
두바이 초콜릿 | 두바이 초콜릿, 두바이초콜릿 | 디저트 | | 두바이쫀득, 두쫀쿠, -호텔
```

## 실행
```
python store_trends.py
```

## 결과 (`output/`)
| 파일 | 내용 |
|---|---|
| `stores_matched.csv` | 찾은 가게 목록 (가게 이름, 개업일, 폐업일, 운영 개월 수, 주소). **유행과 상관없이 이름만 겹친 가게가 섞였는지 꼭 확인** |
| `store_monthly.csv` | 키워드·월별 개업 / 폐업 / 영업 중 가게 수 |
| `store_summary.csv` | 가게 수, 폐업 비율, 검색 정점 대비 개업 정점·폐업 정점 시차(개월), 운영 개월 중앙값, 1년 생존율 |
| `store_survival.csv` | 검색 정점 대비 **언제 창업했는지**(정점 전 / 직후 / 6~12개월 뒤 / 1년 이후)에 따른 운영 개월 중앙값, 1년 생존율 |
| `plots/<키워드>.png` | 위: 검색량, 아래: 월별 개업(+)·폐업(−)과 영업 중 가게 수 |

## 계산 방법
- 아직 영업 중인 가게는 "데이터 기준일까지는 버텼다"로 반영하는 생존 분석(카플란-마이어)으로 운영 기간을 계산한다. 그냥 평균을 내면 영업 중인 가게 때문에 수명이 짧게 계산된다.
- 같은 가게가 여러 파일에 있으면 하나로 합친다.
- 기본으로 2015년 이후 개업한 가게만 본다(`--since`). 오래전부터 있던 같은 이름 가게를 빼기 위해서다.

## 한계
- 가게 이름에 유행 단어가 들어간 곳만 잡힌다. 탕후루를 팔아도 이름이 "○○디저트"면 안 잡힌다.
- 폐업 신고를 늦게 하는 가게가 있어서 실제 폐업보다 날짜가 늦을 수 있다.
